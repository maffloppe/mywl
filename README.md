# mywl — живые подписки для белых списков

Обновляется автоматически каждые ~30 минут: тестер на VPS проверяет тысячи нод,
мёртвые выкидываются, живые проходят проверку IP по CIDR-спискам белых списков.

## Подписки (добавлять ссылку в Happ → Подписки)

| Ссылка (префикс `https://raw.githubusercontent.com/maffloppe/mywl/main`) | Название в Happ | Что внутри |
|---|---|---|
| `sub/test/base64.txt` | wl-ekb Все живые | всё живое, скопом |
| `sub/bs/base64.txt` | Белые Списки — все операторы | только IP из белых списков |
| `sub/mts/base64.txt` | МТС Белые Списки | под МТС |
| `sub/megafon/base64.txt` | МегаФон Белые Списки | под МегаФон |
| `sub/beeline/base64.txt` | Билайн Белые Списки | под Билайн |
| `sub/t2/base64.txt` | T2 Белые Списки | под T2 |
| `sub/motiv/base64.txt` | Мотив Белые Списки | под Мотив |

## Имена конфигов

- `5G/LTE 🇸🇪 Швеция 1` — IP сервера в белых списках, должен работать в шатдаун;
- `Wi-Fi 🇩🇪 Германия 3` — работает без режима белых списков;
- `+ Телеграм` — проверено: через ноду открывается api.telegram.org.
