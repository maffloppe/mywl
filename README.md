# mywl — подписки для операторов РФ во время белых списков

Обновляется автоматически каждые ~30 минут. Узлы проходят проверку IP по CIDR-спискам белых списков, затем тест рукопожатия через сам узел.

## Имена узлов

- `5G/LTE 🇸🇪 Швеция 1` — IP сервера в официальном списке белых списков, должен работать при ограничениях;
- `5G/LTE* 🇩🇪 Германия 4` — IP принадлежит хостингу из списка ASN, но в официальные подсети не попал. Может не открыться при шатдауне;
- `Wi-Fi 🇳🇱 Нидерланды 2` — работает без режима белых списков;
- `+ Телеграм` — проверено, что через узел открывается api.telegram.org.

Узлы отсортированы: сверху те, что дольше держатся в проверках и отвечают быстрее. Порядок обновляется каждый цикл.

## Как проверяется

1. Сбор ссылок из публичных списков и Telegram-каналов.
2. TCP-проверка порта: закрытые узлы отсеиваются до тяжёлого теста.
3. Рукопожатие через каждый узел и запрос `generate_204`.
4. Классификация IP по белым спискам, проверка блокировок РКН.
5. Публикация: один коммит, перезаписывается каждый цикл.
