## Имена конфигов

- `5G/LTE 🇸🇪 Швеция 1` — IP сервера в белых списках, должен работать в шатдаун;
- `Wi-Fi 🇩🇪 Германия 3` — работает без режима белых списков;
- `5G/LTE 🇫🇮 Финляндия 2 + Телеграм` — проверено: через сервер открывается Telegram
